# 精修与成品核验

## 图片插入与内容补齐

统一版式、图组及照片附录按 [学术排版规范](academic-layout.md) 执行，局部修订保持无关结构。

1. 对照用户指定的图号、原图内容和当前源文件，确认新增还是替换。照片、示意图、拟合图各自注明含义；替换图二前同时确认图二与图三的实际对象。
2. 置于相关步骤、现象或数据分析附近，补图注、正文引用和必要来源。检查方向、裁切、比例、文字清晰度、图轴单位及多图对应关系。
3. 用讲义／模板检查缺项。结果、分析和结论以实测及重算输出补齐，原题答案保留核心结论和必要依据。不能把自拟题或未知现象写成实际完成内容。
4. 在报告末尾完成“附录 A：实验原始数据记录照片”，按照片清单核对完整原页、页序、可读性和正文表的对应关系；转录表、裁剪图不能替代完整原照。缺照片时明确列出缺件。
5. 对照原记录核对最终文件的正文原始数据表，确认各组、各次直接读数及列均齐全；处理结果另列。不能将“原始数据已保存在工作簿／附录”视为正文完整。

## 调用文字技能

进入文字润色环节时，在当前技能目录找到并读取以下技能，实际执行其检查：

| 技能 | 在此流程的职责 | 本报告的检查 |
| --- | --- | --- |
| $write-natural-prose | 根据文体、作者原文和上下文统一表达 | 客观、简洁、严谨；保留技术与语义密度，段落衔接自然 |
| $remove-ai-flavor | 局部清理模板句式、说教腔、空泛拔高及机械段落 | 删除无内容的修辞；保留有用推导、必要顺序、准确术语与作者观点 |

正式报告面向阅卷读者，使用客观学术语气；实验前操作指南面向做实验的用户，允许明确的指导句。不要把操作指导压成无法照做的概述，也不要让正式结果分析变成老师讲课。

润色前后比对数值、单位、公式、引用、限定条件和结论强度。只改用户指定部分时保留其余结构。文学性文字的专门确认分支不适用于普通实验报告。

## 调用编译与 PDF 核验技能

- 创建、修订或编译 LaTeX 报告：读取并执行 $manage-academic-latex-paper 的对应流程，保持当前引擎、模板和用户修改。新建结构时才按其要求调用脚手架技能。
- 最终 PDF 生成或更新后：读取并执行 $verify-pdf-output，使用当前技能提供的脚本、标记检查和渲染流程。独立单文件可使用宿主内置编译器；多文件工程按实际构建配置执行，不能把“打开预览”算编译成功。
- 其他格式生成 PDF 时使用对应格式的实际导出工具，仍执行内容与页面检查；不要为了调用 LaTeX 技能强行转换原格式。

| 发现 | 处理动作 | 交付证据 |
| --- | --- | --- |
| 用户修改未出现在成品 | 核对实际源、编译目标、输出目录、构建日志和新旧文本标记 | 新源对应的新 PDF；缓存问题另用新文件名 |
| 编译报错或引用未更新 | 修正具体错误并完成必要重编译 | 成功日志，关键引用和公式完整 |
| 源码字号相同，表格视觉大小仍不一 | 检查缩放、表格宽度、嵌套字号及字体，渲染后比较 | 受影响页面中实际字号、裁切和可读性一致 |
| 新图显示错误 | 检查实际资源、引用及构建结果 | 目标图号的图像内容正确，相关引用正确 |
| 附录有标题但照片缺漏或太小 | 对照原照清单检查每张图；保持与正文一致的页面规格和方向，调整为纵向页上下两张、每页一张或补局部放大图 | 全部已提供记录照片有完整页，手写读数和更正可辨 |

交付前按学术排版规范检查笔者口吻、报告文本、交付源文件注释和 PDF 元数据，确认未带入助手协作或对话过程表述；原始事实、真实来源和科学限制保持准确。

重要输出保存核验记录，包含源／成品路径、构建结果、PDF 与提取文本哈希、页数、新旧标记及已检查页面。新报告检查全部页面；局部修改检查受影响页及因分页重排涉及的页面。

技能或工具缺失时说明具体缺失，继续可完成的内容。未实际编译、文本检查或查看渲染页的环节不得标为完成。
