# 实验报告任务提示词

以下为可调整的任务模板，按当前材料和阶段使用。局部任务只保留对应要求。

## 可复用提示词：整理版

### 实验前：课程 PDF → 报告、记录表与代码


> 请使用 $write-lab-report，读取这份智慧树课程网页或讲义 PDF。按默认学术版式准备报告草稿和可打印的空白原始数据记录表。原理简要，操作指导要让我知道怎么做、观察什么、何时读数、测几次、填哪一栏。记录表覆盖全部必测示数、单位和必要仪器参数。预写数据处理代码并用单独标记的模拟样例验证，实验结果与结论等我提供实测数据再填；末尾预留原始记录照片附录。

### 实验后：识别记录并分析


> 请使用 $write-lab-report，识别这份填写好的原始记录，先整理可核对的转录表，保留示数位数、单位、组别和划改。将全部测量组、各次直接读数和必要条件列成完整原始数据表写入报告正文，再另列计算、不确定度和必要图表，不能只放分析数据。不能确定的读数或换算条件具体列出来。把可确认数据代入代码，据此完善报告，并保留原始记录照片附录。

### 核对后：更正与新增分析


> 请使用 $write-lab-report，以我当前修改过的文件和这次确认的数据为准。按更正重算全部受影响的表格、拟合图、误差、不确定度和结论，再完成我指定的分析。说明关键更正影响了什么，不改动无关结构，也不要覆盖我的其他修改。

### 最后：学术排版、插图、照片附录与文字润色


> 请使用 $write-lab-report，按技能中的学术排版规范统一报告，整体风格参考霍尔效应实验。插图参考示波器的图组安排，按测量顺序放在相关表格或分析附近，默认两张并排，检查读数、图注和引用。补全有依据的内容，并在末尾添加“附录 A：实验原始数据记录照片”，附完整原照并与正文数据表对应。调用 write-natural-prose 和 remove-ai-flavor 润色，保持客观、简洁、严谨、自然的学术语气，保留数据、技术含义和我的修改。最后实际编译，检查正文及全部照片附录。

### 只重新编译和核验


> 请使用 $write-lab-report，只根据我当前指定的最新源文件重新编译并检查 PDF。调用 manage-academic-latex-paper 和 verify-pdf-output 的对应流程，检查最新改动、图号、实际字号和分页。若预览仍显示旧内容，核对源文件和输出路径及文本证据，必要时用新文件名交付。

局部润色、单独补图或特定分析时，只保留相应要求即可。用户已提供的文件、条件和偏好不需反复询问。
