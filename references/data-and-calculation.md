# 数据转录与计算

## 识别到输入的核对

用户需要检查识别结果时，执行[核对交付规范](record-review-delivery.md)。本用户的空白、单位省略及表外记录习惯见[个人记录习惯](user-record-conventions.md)，核对版与计算展开分开保存。

| 观察 | 判断与动作 | 验证／分支 |
| --- | --- | --- |
| 照片有划改、红字或叠写 | 保存原图和原始转录，区分作废值、修正值与设定值 | 无法确定采用哪项时标出具体行列请用户确认 |
| 前行有值、同列后行留空 | 有明确“同上”惯例或用户确认时才沿用，并记录来源 | 不跨独立表；分组或分隔是否中断沿用依已确认约定，本用户不因视觉分隔自动中断；没有适用来源不补零 |
| 多张照片内容相同 | 根据表格内容、拍摄对象及编号判断是否重复 | 同一记录的多次拍照不能算独立重复测量 |
| 原始示数位数不同 | 保留原样字符串，另存用于计算的数值与单位 | 不补零美化；计算结果的有效数字另按方法处理 |
| 当前格未写单位、量程等必要信息 | 查看本表表头、前项及适用说明；本用户省略重复填写时按同上理解 | 明确新值更新；无任何来源才标缺项，不从理论趋势反推倍率 |
| 用户提出读数或量程质疑 | 定位具体照片、表、行、列，分别核对主表和加测表 | 不把不明确的质疑自动变成某个单元格的更正；最新明确更正优先 |

用 CSV、JSON、工作簿或项目已有格式保存输入。需要时保留原图位置、原始文本、采用值、单位、确认状态与更正来源；小任务不强制建立复杂数据库。

记录照片从接收时建立稳定编号，与转录行、正文表及原照附录对应。原文件不覆盖；展示副本中的旋转、裁剪和放大不能改变原始记录，也不能取代附录中的完整原页。

## 正文必须有完整原始数据表

在正文“实验原始数据”或“原始数据与处理”的独立小节列出完整原始表，然后另列处理结果。不能仅给均值、读数差、拟合参数、误差或不确定度表，也不能只链接 CSV／工作簿或用附录照片代替正文表格。

- 覆盖全部测量组和重复次数，保留逐次直接读数、原始位数、单位、方向／加载状态及必要条件。例如左右、初末、正反向读数不能只剩差值或均值。
- 原表中的零点、倍率、环境量及仪器参数按实际记录注明；设定量、实测量和计算量清楚区分。计算结果另列，或以明确的派生列补充，不冒充直接示数。
- 异常、作废和未进入拟合的记录仍在原始表中标注，并说明实际采用情况。用户确认的更正保留来源；不为凑完整表补造缺失值。
- 对照原记录按组核对行数、次数和列，跨页表重复表头；过宽时合理拆表并保留组号、序号和单位，不能缩减测量项。
- 读数不可辨、未记录或缺页时具体标注并确认，已知内容先列齐；缺项未解决前不声称原始表完整。

## 计算前作出判断

1. 以实际装置、接线与操作条件决定模型；讲义方案与实做方案不同时，先核对差异如何影响公式。
2. 把实测量、设定量、标称参数、参考值与拟合结果分开。用户要求用标称值作理论对照时，不能用同组数据拟合出的参数替代。
3. 不确定度按本次讲义或有依据的方法给出。分辨力、精度等级、概率分布、重复次数和相关性各有依据；缺少条件就保留符号、给条件结果或待确认，不能随手采用“常见精度”。
4. 误差、参考偏差、残差与不确定度各按定义使用。没有公认或指定参考值时，不把拟合值或相邻实验值称为真值。

## 执行与检查

- 依用户要求完成逐组计算、必要拟合和图表；保留关键公式、单位、中间结果及必要方法说明。
- 独立检查一个代表性结果及关键单位换算；检查数量级、残差和适用条件。结果偏离预期时先核查录入、单位和模型，保留真实偏差。
- 将原始数据和处理数据对应到报告，图轴、单位、图例和拟合参数与实际计算一致。
- 更正读数、零点、倍率、选择规则或分析方法后重跑依赖链；不只改正文中的最终数字。记录更正前后影响，检查图、表、摘要和结论。
- 不把历史对话中 AI 曾给出的公式、拟合结果或物理解释直接当作已验证规则。
