# 原始数据记录习惯与识别规则

本模块适用于技能所有者已经明确确认的记录习惯。其他用户未确认时不自动套用；具体实验的数值、单位和量程必须以当次记录为准。

## 1. 同表空白沿用规则

同一张表中沿列向下读取，明确的新值更新该条件，后续省略重复填写的空白沿用上一已填值。前项、表头及适用说明均未提供的内容保持未记录，不补零，不跨独立表传播。视觉分组或空白分隔行本身不自动取消此约定。

单位、量程及其他省略重复填写的信息也适用。来源可以是本表表头、同列前项或明确适用的说明；不能仅因当前格未重写而判定缺失。出现明确的新单位、量程或适用条件时使用新内容。所有适用来源均无依据时才标为未记录或待确认。

原样核对版保留实际空白；计算版展开沿用值，并记下来自哪一行或哪项说明。不能因展开计算而改动核对版的原始填写关系。

## 2. 原样转写与表外记录

- 保留列名、列序、填写位置及所有有数字、批注或修改的行。
- 保留行内空白，不能用重新设计的整洁表格覆盖原填写关系。
- 划去旧值与补写新值同时保留；覆盖字迹无法还原时附局部原图，不补造旧值。
- 表头或表外补记保留位置关系，不擅自挪入某个数据单元格。
- 查看整张照片，覆盖主表下方、边缘和空白处。表外加测和补记单独整理并注明原位置，不遗漏或混入主表。

## 3. 当前核对文件优先

用户当前核对表及后续明确更正是计算与报告的依据。旧识别结果、旧 CSV、旧 JSON、旧说明和先前回复不能覆盖用户当前内容。更正撤回时恢复对应项目；同一项以最新明确说明为准。

更正前定位到照片、表、行与列。主表和加测表可能测量同一对象但量程不同，不能只按波长或项目名称连带修改。用户只提出数量级疑问时先核查，不擅自选择某格改数；位置和新值明确后直接更新。

## 4. 示数、倍率与区间分别保存

数字主体、正负号、量程指数、单位和换算值分别核对。显示值相同而指数不同，实际量可能相差一个或多个数量级。换算公式须来自本次仪器和记录，不能当作所有装置的固定规则。

原始记录为区间时，原样表保留区间；若计算采用中点，将中点作为处理量另列，不能替换原始区间。

曲线不连续或数量级异常只提示复核，不证明某个字必然识别错误。不能为了使曲线平滑或接近理论而改数。

## 使用边界

原样展示、计算展开和正式报告排版分别处理。记录习惯必须有所有者的明确确认；没有确认时不推定适用于其他用户。以上规则不授权从理论趋势造数据，也不将个案量程推广到其他测量。
