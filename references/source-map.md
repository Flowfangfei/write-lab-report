# 设计来源与适用边界

本技能从实际实验报告任务中抽取可复用的操作规范。按当前用户要求、课程材料与可验证证据执行；历史报告中的科学解释、数值或完成声明不能代替本次验证。

| 模块 | 设计依据 | 适用边界 |
| --- | --- | --- |
| 四阶段工作流 | 实验前材料准备、实测识别分析、核对更正及最终精修 | 进入当前需要的阶段，局部请求不扩写整篇 |
| 学术版式 | 霍尔效应等实验报告中的章节、公式、表格与分析图组织 | 课程硬性要求优先，默认字号和行距按当前规范执行 |
| 图组排列 | 示波器等实验的截图比较及图表邻近安排 | 不复制固定页码、过度缩放或不规范图注 |
| 数据保真 | 直接示数、位数、单位、重复次数、原表与处理表区分 | 不为接近理论改数，不把拟合参数冒充独立参考值 |
| 原样核对交付 | 可编辑表格、核对 PDF、完整原图与关键局部图 | 识别核对布局不直接充当正式报告的原始数据排版 |
| 已确认的记录习惯 | 省略重复填写、同表空白沿用及更正定位 | 其他用户未确认时不套用；个案数值和量程不推广 |
| 源文件保护 | 当前用户核对文件及最新明确更正优先 | 旧脚本或数据缓存不得覆盖当前编辑 |
| 原照附录 | 完整原始记录页与正文表对应 | 原照、正文原始表与处理结果均保留，不能相互替代 |
| 成品验收 | 最新源、文本标记、构建与渲染页面分别核验 | 时间戳或哈希变化不单独证明内容与版面正确 |

发布包保留执行规范和任务模板，不包含原始对话、用户逐字摘录、会话标识、真实实验数据或私人附件。该包可独立读取，不依赖原数据库或来源项目。

文件完整性与静态检查不等于真实任务成功率；未报告受控条件下的有／无技能配对收益。
