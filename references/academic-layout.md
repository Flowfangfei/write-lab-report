# 学术排版、插图与原始照片附录

用于新建、补全或统一整篇实验报告。优先级为用户本次明确要求、课程硬性格式、本规范；局部修改保留其余现有结构。默认值可因真实版面条件调整，调整后以最终 PDF 的可读性和一致性验收，不反复询问普通排版选择。

## 整体风格与默认值

整体采用霍尔效应样本的朴素学术风格：明确的章节层级、连贯正文、公式、三线表及与分析相邻的图。其他实验报告可补充做法；无需仿制每一处分页、标题间距或篇幅。

| 项目 | 默认规范 | 检查方式 |
| --- | --- | --- |
| 页面 | A4 纵向，四边页边距 2.5 cm；正文和图表均在版心内 | 查看渲染页，不只检查参数 |
| 正文 | 12 pt；中文宋体或相近宋体，英文和数字使用配套衬线字体；1.5 倍行距，首行缩进 2 字符，段前后不额外堆空行 | 中英混排自然，全文字号、行距与段落密度一致 |
| 题目 | 居中、加粗，通常 18–22 pt；不使用装饰横幅、彩色大块或宣传式副标题 | 题目与信息栏不挤占过多首屏空间 |
| 标题 | 编号层级以 1、1.1、1.1.1 为例；一级约 16 pt、二级约 14 pt、三级与正文同级加粗，最多按实际需要展开 | 无孤立页末标题、跳号或过碎的小标题 |
| 页码与信息 | 连续页码；只填写已提供的必要信息，默认不另做空白封面页 | 姓名、学号等不复制样本；实验日期不能用编译日期冒充 |
| 表格 | 统一表头、量名与单位，优先三线表；字号通常 10.5–12 pt，表题在上 | 不超版心，不把宽表缩成小字；原始示数不因对齐补零 |
| 公式 | 重要公式独立居中，正文解释必要符号、单位与适用条件；需要引用时编号 | 公式不断裂，变量和单位规范，引用正确 |
| 图与图注 | 图居中，图注在下；图、表分别连续编号；图注及表题通常 10.5 pt | 字号一致，图号与正文引用对应，无多余星号或占位文字 |

中文 LaTeX 按项目可用引擎和字体构建；字体不可用时选择可用等效字体并检查字形，避免为凑样本字体破坏可编译性。上述字号、行距等统一为当前用户授权的默认规范，不声称全部逐项照抄自某份旧报告。

章节按讲义覆盖实验目的、简要原理、仪器、方法／步骤、原始数据与处理、分析及误差／不确定度、结论、指定思考题、附录。实验简介、扩展推导等有实际内容才加。每项数据分析尽量形成“条件与原始量—方法／计算—表或图—结果及解释”的连续文段，不为凑栏目重复同一结论。

**正文必须有完整的实验原始数据表**，逐组、逐次呈现实测示数及单位、原始位数和必要条件；随后另列处理结果表。正文原始表、分析结果和附录原照三者均需保留，各自对应。不能只放分析数据、代表性几行、均值或原始照片；长表用续表，宽表拆分并保留序号，不删原始测量项。

## 作者口吻与交付文字

这是本用户跨实验复用的报告写作偏好：正式报告以客观学术口吻陈述实验事实，不叙述报告制作和数据到达最终状态的过程。删除识别转录、核对确认、覆盖字迹、划改取舍、旧值与采用值的变更经过，以及“经笔者确认”“采用确认后的读数”“原值更正为”“保留划改”“取得资料后更新”等直接或间接暗示。原始记录来源只注明材料本身，例如“本次实验原始数据记录 PDF，4 页”。

报告正文、图注、附录、参考文献、页眉页脚、交付源文件的注释及 PDF 元数据中，不加入 AI、助手、提示词、工具协作或生成过程说明。交付前逐段通读全文，并检查 PDF 文本和元数据；检查范围包括正文、图注、参考文献、附录说明及页眉页脚，不能只删除几个关键词。技术术语、实验方法、真实资料来源和必要科学限制照实保留；以客观条件描述测量局限，避免写成等待材料、补充核对或再次修订的工作状态。

项目规范要求的内部过程记录、原样核对版、运行日志和核验记录单独保存，不嵌入报告成品，也不作为报告正文交付。正文采用值及完整原照保留；去除过程性文字不等于改写原始读数或涂抹原照笔迹。

## 插图分组：参考示波器样本

先判断图是拟合结果、装置图、波形截图还是纸质原始记录照片，再决定放置与大小。

| 观察／条件 | 排列动作 | 验证与分支 |
| --- | --- | --- |
| 一张主要曲线或装置示意图 | 通常用 0.70–0.90 倍正文宽度，按内容居中 | 图内标签可读，正文有对应分析 |
| 同类截图需比较 | 默认每行两张，每个子图容器约 0.48 倍正文宽度，保持等宽、对齐和原比例 | 同组按用户给定或测量顺序排列，不能因好看交换条件 |
| 六张同类读数截图 | 优先两列三行；高度上限可从约 0.18 倍正文高度试排，保留宽高比 | 若刻度变小或图组过高，拆组、分两页或增大单图；不为凑一页牺牲读数 |
| 三张简单截图 | 仅在屏幕读数可辨时每行三张，容器约 0.32 倍正文宽度 | 图内文字不清就改成两列或单列 |
| 多图对应不同条件 | 用 (a)、(b) 等子图标识，图注或正文说明对应条件、量和顺序 | 不只写“这是截图”而不说明与表中哪组数据对应 |
| 表中需要逐行对照照片 | 可在表内放缩略图，正文／附录另保留清晰版本 | 不把复杂截图塞进窄单元格充当唯一读数依据 |
| 图组靠近相关表、但当前页容不下 | 优先自然移到紧邻下一页，必要时拆成有说明的两组；检查浮动与分页 | 有条件使用固定位置，不能要求所有图都用 H；不复制旧报告“固定第四页”的指令 |

图片保持宽高比；可以在用于展示的副本上旋转、去掉无关背景或做透视校正，不能裁掉坐标轴、单位、有效示数或测量条件。原文件保留不覆盖。图注使用规范编号及可引用标签；无编号图注需正确配置支持，不得交付出现“图 1: *”等编译副产物。

示波器历史记录的后续要求是取消独立一页限制、让图组紧接相位差表。通用规则是让图与对应数据邻近，并以渲染页核验实际位置。其旧表格整体缩放方式不作为统一字号的默认方案：宽表先调列宽、换行表头、合理拆表或单独横向页，避免每张表缩放倍率不同。

## 必须保留的原始记录照片附录

新建、补全或最终交付整篇实测报告时，正文结论和指定思考题之后设置“附录 A：实验原始数据记录照片”。操作指南、扩展计算等另作后续附录，不占用原照附录。

1. **先列清单**：为本实验已提供的全部记录照片编号 A-1、A-2……，记录原文件、记录页／测量组别、对应正文表和是否已入附录。包括手写更正和作废标记，不因数据未被采用而抹掉记录。
2. **保留原件**：原图按原样保存。正文可用转录表或局部读数图，附录必须包含完整的原始记录页面；不能用重绘表格、重新打字或 AI 生成图片替代。旋转及清晰化展示副本与原文件建立对应，不能覆盖原件或改写笔迹。
3. **统一页面并按可读性排图**：附录的页面尺寸、方向、页边距和页码格式与正文一致，默认全篇 A4 纵向；不得仅因原始图片是横向就旋转附录页面或另设横向纸张。横向完整原页可在纵向页面上下排两张，保持原图比例、顺序和独立图注，并以字迹清晰及版面均衡验收。两张缩小后不可辨时改为同规格纵向页一页一张，或在完整原页之外增加局部放大图，不裁掉有效记录、不拉伸图片，也不用放大图替换完整页。
4. **写清出处**：附录图注如“图 A-1 原始记录第 1 页，对应正文表 1、表 2”；正文数据表可注明“原始记录见附录 A，图 A-1”。原始仪器读数截图被用作数据依据时，也纳入对应清单；装置照片单独说明用途。
5. **查完整性**：对照原文件逐张看附录渲染页，确认边缘、页序、数字、符号、单位、零点／倍率说明和划改均可辨认。附录文字标记出现不代表照片已正确嵌入。重复拍摄同一页可选最清晰一张并保留对应关系，不重复计为独立记录；有新增信息的照片都保留。
6. **处理缺件**：实验前只预留附录标题和待补说明，不嵌入样例照片。实验后材料中缺照片、页码或关键部分时明确列出缺件并继续其他工作，不伪造原照或声称附录齐全；收到照片后补齐并重新编译核验。

原始照片及其附录按当前项目隐私规则在本地保存；生成报告不扩展为公开发布或向其他服务上传原始记录的授权。

## 交付前的页面检查

检查首页、章节过渡、每个图组、每个宽表和全部原照附录。确认全篇页面尺寸和方向一致，横向原照在纵向页中的比例、分组和读数清晰；确认字号、对齐、页边距、图注、条件对应及清晰度；修复溢出、表格字过小、孤立标题、无意义空白和星号图注。保留实际检查过的页码及未取得的原照清单。

本规范由用户指定霍尔效应整体风格、示波器插图安排及其他报告共同参考而来。过去的个人信息、实验数值、自动日期、特定页码和未经核验的科学结论不进入通用默认值。
